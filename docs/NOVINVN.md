# داشبورد فروش و آدرس novinvn://report

## چه چیزی اضافه شد (نسخه 1.14.0)
داشبورد «هوشمند فروش نوین» (Opportunity Sales Dashboard) به‌صورت ماژول `src/report/` داخل افزونه آمد. روی صفحهٔ CRM به‌صورت overlay باز می‌شود و داده را با همان نشست وارد‌شده‌ٔ کاربر از Web API می‌خواند (بدون توکن).

نسبت به اسکریپت قبلی: TypeScript و تست‌شده؛ تقویم شمسی دقیق (jalali مشترک افزونه) و مرز روزها بر پایهٔ نیمه‌شب تهران؛ فونت Vazir خود افزونه (بدون اتصال به Google Fonts)؛ صفحه‌بندی بدون سقف.

## راه‌های باز کردن
| روش | توضیح |
|---|---|
| `novinvn://report` | بعد از نصب هندلر ویندوز (پایین): هر جا تایپ/کلیک شود Chrome روی CRM باز می‌شود و داشبورد بالا می‌آید |
| نوار آدرس Chrome | `nv` ← Tab ← `report` ← Enter. اگر تب CRM باز باشد همان‌جا فعال می‌شود، وگرنه تب جدید |
| لینک داخل CRM | هر `<a href="novinvn://report">` داخل صفحات CRM |
| دکمهٔ شناور «گزارش فروش» | در لیست فرصت‌ها (کنار «فرصت جدید») |
| آدرس مستقیم | `https://<crm>/main.aspx?novinvn=report` (پارامتر بعد از باز شدن از آدرس حذف می‌شود) |

## چرا یک هندلر ویندوز لازم است؟
Chrome اجازه نمی‌دهد افزونه خودش اسکیم `novinvn://` را ثبت کند (فقط `web+…` یا فهرست مجاز). پس اسکیم در خود ویندوز ثبت می‌شود و فقط آدرس را به لینک CRM ترجمه می‌کند.

نصب: روی `tools/protocol/install-novinvn.bat` دوبار کلیک کنید (برای هاست دیگر، آدرس داخل فایل را عوض کنید). نیاز به Admin ندارد؛ فقط برای کاربر فعلی ثبت می‌شود. Chrome بار اول می‌پرسد «باز شود؟» — گزینهٔ «همیشه اجازه بده» را بزنید. حذف: `uninstall-novinvn.bat`.

مسیرهای (route) جدید بعداً با افزودن یک خط در `ROUTES` (`src/report/index.ts`) و یک `Case` در handler اضافه می‌شوند.

## نکات
- هندلر فقط برای Chrome روی ویندوز است؛ اگر Chrome پیدا نشود مرورگر پیش‌فرض را باز می‌کند.
- اگر کاربر وارد CRM نشده باشد، بعد از ورود دوباره `novinvn://report` را بزنید.
- فیلترها و تنظیمات (ریال/تومان، مبنای تاریخ، تم) در localStorage مرورگر ذخیره می‌شود.

## عیب‌یابی: در نوار آدرس Chrome جستجوی Google باز می‌شود
Chrome متنی مثل `novinvn://report` را فقط وقتی «آدرس» حساب می‌کند که اسکیمش در ویندوز ثبت شده باشد؛ وگرنه جستجو می‌کند.
1. مطمئن شوید `install-novinvn.bat` اجرا شده و «Done» نشان داده است (در رجیستری باید `HKEY_CURRENT_USER\Software\Classes\novinvn` وجود داشته باشد).
2. Chrome را کامل ببندید (از Task Manager هم پروسه‌های chrome.exe) و دوباره باز کنید.
3. تست مستقل از Chrome: `Win + R` ← `novinvn://report` ← Enter. اگر اینجا کار کرد، هندلر سالم است.
4. اگر در Win+R کار کرد ولی نوار آدرس باز هم جستجو می‌کند، از راه‌های زیر استفاده کنید که به ثبت اسکیم وابسته نیستند: `nv` ← <kbd>Tab</kbd> ← `report`، دکمه‌ی «گزارش فروش» در لیست فرصت‌ها، یا یک Bookmark با آدرس `https://<crm>/main.aspx?novinvn=report`.
