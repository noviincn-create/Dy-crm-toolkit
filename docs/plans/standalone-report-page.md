# برنامه: داشبورد فروش به‌صورت صفحه‌ی مستقل (نسخه ۱.۱۵.۰)

**هدف:** `novinvn://report` یک صفحه‌ی کامل و جدا از Dynamics باز کند (صفحه‌ی خود افزونه، `chrome-extension://…/report.html`)، نه overlay روی CRM.

## تصمیم‌های طراحی
- **صفحه‌ی افزونه:** `public/report.html` + `src/report/page.ts`. نمودارها و جدول‌ها همان ماژول‌های فعلی‌اند؛ فقط میزبان عوض می‌شود.
- **داده:** صفحه‌ی افزونه با `host_permissions` و کوکی مرورگر مستقیم Web API را می‌خواند (همان روش جلسه‌ی سریع). نیازی به باز بودن تب CRM نیست، فقط باید قبلاً وارد CRM شده باشید.
- **مسیریابی بدون وابستگی به ID افزونه:** افزونه‌ی unpacked ID ثابت ندارد. پس هندلر ویندوز آدرس `https://<crm>/__novinvn__/report` را باز می‌کند و یک قانون `declarativeNetRequest` آن را پیش از رسیدن به سرور به `report.html` تغییر مسیر می‌دهد.
- **راه‌های دیگر:** omnibox (`nv report`) و دکمه‌ی «گزارش فروش» در لیست فرصت‌ها به همین صفحه می‌روند؛ اگر تب گزارش باز باشد همان فوکوس می‌شود.
- **حذف:** overlay روی CRM (اسکریپت MAIN `content/report`) و تریگر `?novinvn=`.

- [ ] **M4** مستندات (README، NOVINVN.md)، نسخه‌ی ۱.۱۵.۰، بیلد نهایی و push

## ریسک‌ها
- ریدایرکت DNR به صفحه‌ی افزونه برای ناوبری بیرون از مرورگر باید در Chromium واقعی تأیید شود (M3). اگر کار نکند، برنامه‌ی جایگزین: صفحه‌ی راه‌انداز کوچک روی CRM که فقط تب را به `report.html` منتقل می‌کند.
- نشست CRM: اگر کاربر وارد نشده باشد، صفحه پیام «ابتدا وارد CRM شوید» و دکمه‌ی باز کردن CRM نشان می‌دهد.
